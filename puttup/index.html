PuttUP · 2D Minigolf

A 2D minigolf simulation with physics-based ball behaviour, local multiplayer and a built-in track editor. Developed in Java as a university software engineering team project (2015/16).

Loads about 18 MB on first start. Needs a desktop browser and a mouse.
